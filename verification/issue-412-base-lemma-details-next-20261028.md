# Issue #412: 基本形の説明追加（続き）

2026-10-28。固定 Mozc 品詞分類の動詞・形容詞の基本形から、既存の
coverage とレビュー済み LLM release に同じ読み・表記がない候補を抽出。
意味を直接確認できる190件にプロジェクト作成の説明を追加した。
特殊な読み、曖昧な語義、循環的な説明は採用対象から外した。
説明専用入力は既存の exact identity・cost・flags と照合し、既存の
活用形継承処理は生成元が一意な場合だけ基本形の意味として表示する。

| 項目 | 追加前 | 追加後 |
| --- | ---: | ---: |
| 全 entry | 661,428 | 661,428 |
| 説明付き entry | 51,479 | 53,567 |
| 生成活用形への継承 | 20,091 | 21,989 |
| 説明なし | 609,949 | 607,861 |
| 辞書画像 | 39,508,052 bytes | 39,584,492 bytes |

増分2,088件は基本形190件と継承活用形1,898件。curated import は
入力と出力が190件ずつ増え、既存説明による抑制は1件のまま。追加前の
51,479件は ordinal ごとに説明・表示用説明・関連語がすべて一致した。
追加前に説明がなかった「食べない」は、追加後「「食べる」の活用形。
基本形の意味：食物を口に入れてのみ込む。」を返した。

  DREC、DREL、DTOF、DTXT のみ。
- 両画像で `issue_94_`、`issue_348_`、`issue_390_`、`issue_392_`
  の候補順位テストに成功。

  `ci/check-process-clean.ps1` で対象プロセスなしを確認。

## 速度

同一マシンの release build で追加前後を順に測定。通常変換と bridge は
各500 warmups・5,000 samples、画像 open と短い候補検索は31 samples、
詳細検索は101 warmed samples。測定は各1回であり、差が変更によるものか
計測ばらつきかは判別できない。

| 対象 | 追加前 p50 / p99 | 追加後 p50 / p99 |
| --- | --- | --- |
| 通常変換 | 0.866 / 1.514 ms | 0.891 / 1.554 ms |
| cross-commit bridge あり | 1.440 / 2.396 ms | 1.481 / 2.459 ms |
| 4種類の候補検索・表示 | 1.102 / 2.107 ms | 1.286 / 2.609 ms |
| 辞書 open・検証 | 55.203 / 65.129 ms | 52.972 / 60.204 ms |
| 既存「書く」詳細検索・preview | 0.1 / 0.1 μs | 0.1 / 0.1 μs |
| 新規「食べない」詳細検索・preview | 説明なし | 0.1 / 0.2 μs |

openには OS cache が含まれる。実アプリのキー入力、UI描画、冷間起動、
長期的に大量の説明を追加した場合の性能は測定対象外。説明付き割合は
約8.10%であり、残りの語義には継続的な確認が必要。
