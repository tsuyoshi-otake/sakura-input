草案を除いて160件の説明を追加した。付与対象は読み・表記・ID・cost・
flagsが一致する既存entryに限る。

増分2,326件は基本形160件、生成活用形1,691件、既存活用形475件。
既存説明によるcurated import抑制は前後とも1件。「売り」は追加後に
「「売る」の活用形。基本形の意味：代金と引き換えに品物を渡す。」を
返す。30%に必要な198,429件まで残り132,016件。

固定Japanese WordNetのLMFは `Lemma` に品詞を持つ。ただし同一表記・
品詞でも異なるsenseを含む。例えば「銀行」は金融機関と建物に加えて
賭場の資金や貯蔵に関する定義も持つことを固定XMLで確認した。辞書entry
の読みと品詞だけで個々のsenseを確定できず、自動一括付与は行わない。

## 速度

同一マシンのrelease buildで追加前後を順に測定。通常変換とbridgeは各
500 warmups・5,000 samples、画像openと短い候補検索は31 samples、
詳細検索は101 warmed samples。各1回の比較であり、測定環境のばらつき
と変更による差は区別できない。p50 / p99は以下のとおり。

| 測定 | 追加前 | 追加後 |
| --- | --- | --- |
| 通常変換 | 0.986 / 1.705 ms | 0.848 / 1.503 ms |
| cross-commit bridge | 1.620 / 2.671 ms | 1.409 / 2.388 ms |
| 4種類の候補検索・表示 | 1.086 / 2.024 ms | 1.111 / 2.000 ms |
| 辞書open・検証 | 48.138 / 62.315 ms | 55.330 / 67.829 ms |
| 既存「食べない」詳細検索・preview | 0.1 / 0.2 μs | 0.1 / 0.2 μs |

openはOS cacheを含む。実アプリのキー入力・画面描画・冷間起動や、
さらに大量に説明を増やした場合の性能は測定していない。
