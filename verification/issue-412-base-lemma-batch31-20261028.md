## Ownership, scope and residual risk

Curated base-lemma data owns the meanings; compiler native inheritance owns matching and preservation. The new rule uses the existing exact reading, surface, POS and conjugation-class matching, all-parent uniqueness and final-entry preservation contract. It does not change runtime state or the ranking contract. Scope covered the curated data, compiler and its tests, image benchmark, decision and this verification record. Investigation expanded to the two distinct Mozc サ変 classes because they have different IDs; both are explicitly tested. Future similar changes can reuse the native inheritance boundary, but must identify each source conjugation class and individually review meanings. The 30% milestone remains incomplete.
