## 速度

同一マシンのrelease build、各500 warmupsと5,000 samples。最初は追加前→
追加後、再測定は追加後→追加前で順序を逆にした。各回の p50 / p99:

| 測定 | 追加前 | 追加後 |
| --- | --- | --- |
| 通常変換・1回目 | 0.872 / 1.475 ms | 0.959 / 1.667 ms |
| 通常変換・再測定 | 0.832 / 1.455 ms | 0.836 / 1.460 ms |
| bridge・1回目 | 1.439 / 2.315 ms | 1.603 / 2.652 ms |
| bridge・再測定 | 1.391 / 2.297 ms | 1.397 / 2.326 ms |

辞書open・検証の31 samplesは52.029 / 59.355 ms → 55.624 / 96.074 ms、
候補検索31 samplesは1.155 / 1.823 ms → 1.738 / 4.009 ms。小標本と
OS cacheを含み、後者の遅延は通常変換の再測定で再現を確認できていない。
複数回の比較でも環境変動と変更による影響は区別できない。実アプリの
キー入力・画面描画・冷間起動は測定していない。
