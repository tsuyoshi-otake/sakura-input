# Issue #412: 基本形の説明追加

2026-10-28。説明のない基本形から、意味を確かめやすい一般的な動詞・
形容詞53件に、プロジェクトが作成した説明を追加した。Mozc の固定品詞
情報で基本形を選び、既存 coverage とレビュー済み LLM release の両方を
除外した。語義が曖昧な候補、循環的な説明、用法の限定が疑わしい読みは
採用していない。採用した説明は各行を直接確認した。

説明専用入力は、既存 entry の読み・表記・品詞 ID・コスト・flags を
照合して付与する。活用形への継承は従来どおり生成元が一意な場合だけで、
否定形などにも「基本形の意味」と明記する。

| 項目 | 追加前 | 追加後 |
| --- | ---: | ---: |
| 全 entry | 661,428 | 661,428 |
| 説明付き entry | 50,999 | 51,479 |
| 生成活用形への継承 | 19,664 | 20,091 |
| 説明なし | 610,429 | 609,949 |
| 画像サイズ | 39,489,620 bytes | 39,508,052 bytes |

増分480件は基本形53件と継承活用形427件。curated import は入力・出力
とも53件増加し、既存説明による抑制は1件のまま。旧画像の50,999件は
全 entry ordinal について説明・表示用説明・関連語が完全に一致した。
追加前に説明のなかった「歩かない」は、追加後に「「歩く」の活用形。
基本形の意味：足を交互に動かして進む。」を返した。

## 速度

同一マシンの release build で追加前後を順に測定。通常変換と bridge は
各500 warmups・5,000 samples、画像 open は31 samples、詳細検索は
101 warmed samples。1組の測定なのでばらつきと変更の影響は区別できない。

| 対象 | 追加前 p50 / p99 | 追加後 p50 / p99 |
| --- | --- | --- |
| 通常変換 | 0.855 / 1.479 ms | 0.839 / 1.438 ms |
| cross-commit bridge あり | 1.419 / 2.322 ms | 1.396 / 2.277 ms |
| 辞書 open・検証 | 47.884 / 53.578 ms | 47.814 / 50.873 ms |
| 既存「書く」詳細検索・preview | 0.1 / 0.1 μs | 0.1 / 0.1 μs |
| 新規「歩かない」詳細検索・preview | 説明なし | 0.1 / 0.2 μs |

open は OS cache を含む。UI描画、実アプリのキー入力、冷間起動、今後の
大幅な説明追加の性能は測定していない。説明付き割合は約7.78%であり、
残りを100%にするには、基本形以外も含めた継続的な語義確認が必要。
