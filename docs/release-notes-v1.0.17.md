# Sakura Input 1.0.17

日付の読みと「24日」のような数字日付を、IMEらしい候補へ直します。生成AIの変換・校正中は、待ちだと分かる表示を出します。

## 変更

- `きょう` / `こんにち` / `ほんじつ`、`あさって` / `みょうごにち`、`らいしゅう`、`せんしゅう` を変換すると、語のあとに令和・西暦（曜日あり／なし）、`2026/8/19` と `2026-08-19` 形式の日付候補が並びます。`きょうは` のような句には日付を足しません。
- `にじゅうよんにち`、`にじゅうよっか`、`24にち` は先頭が `24日` になり、全角の `２４日` と `二十四日` も出します。上付きの `²4日` や `二重呼ん` のような同音の切り張りは出しません。
- 生成AIの文章変換・選択文字列校正が走っているあいだ、そのアプリのマウスポインターを「処理中でも操作できる」カーソルへ変え、言語バーのツールチップに `AI変換中…` / `AI校正中…` を出します。完了・失敗・フォーカス移動で元に戻します。

## 対応環境

Windows 11 build 22000以降、x64、AVX対応CPU。32 bitホスト用DLLとARM64ネイティブ版は含みません。

## インストール前の確認

このリリースの`sakura_setup.exe`はローカルビルドで、Authenticode署名を含みません。署名の検証はできないため、GitHubのReleaseページから取得し、公開されているSHA-256と一致することを確認してください。

アップグレードはversioned payloadのside-by-side切替で行われます。neural payloadの検証に失敗した場合は、新しいTSF登録へ切り替えずinstallationを中止します。
