# Sakura Input 1.0.35

一般的な変換で「ずみ」から「済み」「済」が候補に出ない辞書欠落を修正しました（#85）。個別語だけを上書きするのではなく、原本にはあるのに同梱辞書から消えていた語を全件監査し、同種の欠落を構造的に防いでいます。

## 主な変更

- Mozc原本で接尾語用の品詞行しか持たないreading／surfaceを、同梱辞書の先頭候補から一律に除外していたtrim規則を見直しました。
- 対象287組を全件監査し、通常の語頭変換を許可する60組と、接尾語専用のまま維持する227組を明示ポリシーへ固定しました。
- 「ずみ」では「済み」「済」を復元する一方、接尾語としてだけ使う「ずかい」の「使い」「遣い」などは語頭候補へ昇格させません。
- 実際に生成した同梱辞書を使う回帰テストと、監査対象の過不足を検出する全件テストを追加しました。一般日本語の候補欠落を直しても、同音異義語や接尾語境界が崩れないことを確認します。

## 更新方法

v1.0.34では、設定画面の更新確認または次のコマンドから更新できます。

```text
sakura_settings.exe update apply
```

v1.0.32以前はSakura update-signing v2の公開鍵を持たないため、先にv1.0.33以降を一度だけ手動インストールしてください。

## Authenticodeについて

このReleaseはowner承認済みのAuthenticode未署名版です。Windowsのダイアログには「不明な発行元」と表示されます。有償証明書は使いません。

未署名installerを無条件には許可しません。Sakura manifest署名が正しく、manifestが`authenticode=unsigned`を宣言し、`WinVerifyTrust`が正確に`TRUST_E_NOSIGNATURE`を返した場合だけ更新を続行します。不正署名、失効署名、未知provider、policy不一致はfail closedで拒否します。

## 対応環境

Windows 11 build 22000以降、x64、AVX対応CPU。32 bitホスト用DLLとARM64ネイティブ版は含みません。
