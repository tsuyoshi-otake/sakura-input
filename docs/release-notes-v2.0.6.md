# Sakura Input 2.0.6

- 開発者モードの入力履歴を有効にするとき、大きな履歴の検証をバックグラウンドで進め、キー入力を待たせないようにしました。無効化すると履歴収集と診断トレースを停止し、処理中の保存は所有するスレッドで終了させます。
- 入力履歴の整理中に書き込みが途切れた場合の復旧判定を修正しました。元の保存内容と計画を検証できる場合だけ復旧し、矛盾するデータや不明な状態は変更せず残します。
- 入力履歴が64 MiBの上限に達した際の保存処理を改善しました。同じ暗号化データの検証を繰り返さず、新しい入力履歴の保存待ちが膨らむ問題を軽減します。
- 切断済みアプリの記録を最新1,024件に制限しました。入力中のアプリを保護する状態は維持します。上限を超えると最も古いアプリの「切断後のSpaceを一度だけ吸収する記録」は失われます。
- 使われていない初期化・変換・設定・テスト用の関数を整理しました。意図的に保持する研究コードと診断用の数値タグは残しています。

履歴の復旧判定を含む7つの判定に、MCC 28通りとMC/DC 14条件の検証を適用しています。アプリ全体のMC/DC網羅率ではありません。

レンダラーのメモリ増加はIssue #260で引き続き調査しています。このリリースでレンダラー全体のメモリリーク解消を確認したとはしていません。

このインストーラーはAuthenticode未署名です。手動導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では署名付き更新manifestによるサイズ・SHA-256・未署名状態の検証を行います。
