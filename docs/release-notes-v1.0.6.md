# Sakura Input 1.0.6

1.0.5 以降の入力修正と、GPT-5.6 Luna による文章変換・校正をまとめたリリースです。同梱辞書と Sakura-Rerank-Tiny-v1 は 1.0.5 と同一です。

## 変更

- Shift を押したままの英字入力で、Backspace のあとに打ち直すと文字順が入れ替わる問題を修正しました（`4ab9aeb`）。

  Shift 押しっぱなしの Backspace が未割当になり、画面上の英語キャレットと内部の `raw_input` が別管理になっていました。削除して打ち直すと、押した順と違う並びに戻ることがありました。Shift 組み合わせを割り当て、キャレットを `raw_input` に揃え、独立した oracle・PBT・TLA+ で順序を固定しています。

- Shift 中の ASCII composition に、入力したスペースをそのまま残せるようにしました（#56）。
- エンジンがタイムアウトから復帰するあいだ、ホストへ漏れたキーを隔離するようにしました（#57）。
- GPT-5.6 Luna の文章変換と、選択文字列の校正を追加しました（#58）。

  文章変換は明示操作だけで始まります。既定キーは JIS の `変換` で、`Caps Lock` か無効にも変更できます。入力中の preedit を優先し、なければホストの空でない選択範囲を対象にします。対象がない場合は、従来のキー動作へ戻します。校正はタスクバーメニューから選択文字列に対してだけ起動し、入力中は拒否します。

  モデルは `gpt-5.6-luna`、通信は Responses API だけです。API キーは Windows Credential Manager のみに保存し、通常の入力欄を含む `Normal` スコープ以外では起動しません。ログオン直後のプロファイル修復と、InputScope を持たない通常の入力欄でも文章変換が始まるよう、#58 の後続修正を含みます。

## 対応環境

Windows 11 build 22000以降、x64、AVX対応CPU。32 bitホスト用DLLとARM64ネイティブ版は含みません。

## インストール前の確認

このリリースの`sakura_setup.exe`はローカルビルドで、Authenticode署名を含みません。署名の検証はできないため、GitHubのReleaseページから取得し、公開されているSHA-256と一致することを確認してください。

アップグレードはversioned payloadのside-by-side切替で行われます。neural payloadの検証に失敗した場合は、新しいTSF登録へ切り替えずinstallationを中止します。
