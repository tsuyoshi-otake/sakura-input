# Sakura Input 2.0.12

- 開発用の変換評価ツール `ime-eval` の `capture` が、候補が64件を超える読みで実行全体を失敗させていた問題を直しました（#297）。ローマ字入力のケースは、エンジンが返した順に先頭の64件を記録し、切り詰めたケースを標準エラー出力と記録ファイルの `truncated` に残します。かな入力の品質評価の上限（18件）と、記録ファイルの形式は変わりません。

このリリースでは、IME本体（変換エンジン、TSF、候補ウィンドウ、設定画面、辞書）の動作に変更はありません。`ime-eval` はインストーラーに含まれない開発用ツールです。

このリリースの検証は、`ime-eval` の単体テストと実エンジンを使った結合テスト（修正前のコードでは失敗することの確認を含む）、ワークスペース全体のテスト、リポジトリのCIゲートです。インストールしたIMEでの画面上の変換確認は、リリース時点では行っていません。

このインストーラーはAuthenticode未署名です。手動導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では署名付き更新manifestによるサイズ・SHA-256・未署名状態の検証を行います。
