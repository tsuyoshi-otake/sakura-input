# Contract inventory

This file is the authoritative filename and owner inventory for the 23 contracts in the architecture plan. The contract documents listed below are planned files: they are intentionally shown as code-formatted filenames rather than links until Phase 7.5 creates them.

Until each migration is complete, the linked current source remains canonical. A migration must create the contract document, add a back-reference from the canonical code, record its version and compatibility policy, and link its verification artifact. Moving code between crates does not transfer contract ownership unless this inventory is updated in the same change.
