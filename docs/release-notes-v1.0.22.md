# Sakura Input 1.0.22

「ばん」で「版」が出ない、「運用」を確定した後の「び」で「日」が出ない、といった不便を、語ごとの例外追加ではなく、辞書の品詞根拠を使う共通規則で修正するリリースです。

## 主な変更

- 連濁した接尾語を単独候補から抑止する条件を見直しました。同じ表記の清音読みに、接尾語・接頭語・非自立語ではない独立語の根拠が残っている場合だけ、連濁形を語頭不適切として扱います。
- 接尾語同士の循環的な根拠では候補を消さないため、`ばん`の`版`、`び`／`ぴ`の`日`、`どき`の`時`、`がた`の`方`、`がえ`の`替え`を独立変換で利用できます。これにより、`運用`を先に確定してから`び`を`日`へ変換する入力も改善します。（#85）
- 全文を続けて入力する`うんようび`→`運用日`に加え、`てんけんび`→`点検日`、`さぎょうび`→`作業日`、`こうかいび`→`公開日`、`こうしんび`→`更新日`、`けんしゅうび`→`研修日`を実辞書で回帰検証します。
- `ずかい`から不自然な`使い`／`遣い`を除く既存の汎用抑止と、`きづかい`、`こづかい`、`ことばづかい`など複合語内部の正しい連濁は維持します。
- 単語固有のallowlist／blacklistは追加していません。

## 検証

- 固定したMozc・smile-chat・Japanese WordNet・審査済み辞書詳細を使って出荷辞書を2回ビルドし、byte-for-byteの決定性を確認しました。`system.dic`は46,732,992 bytes、SHA-256は`4aca62dd036944e72556371aa698c3068e4fd21340bee2f01863af121fa5363b`です。
- 出荷辞書は604,587 entries、30,873 details、`NON_INITIAL` 494件です。今回の規則見直しで、6 entries／5 readingsだけが独立候補へ戻ることを差分監査しました。
- 実辞書テストで、上記の「日」複合語、単独の`び`／`ぴ`／`どき`／`がた`／`がえ`、`ばん`の`版`、既存の`ずかい`抑止と正しい複合語維持を確認しました。
- workspace全体のformat、Clippy、test、diff check、残存cargo／rustc／test process 0を確認しています。release workflowでも生成直後の実辞書に対して同じ回帰テストを明示実行します。

## 対応環境

Windows 11 build 22000以降、x64、AVX対応CPU。32 bitホスト用DLLとARM64ネイティブ版は含みません。

## インストール前の確認

このReleaseはowner承認済みのAuthenticode未署名版です。GitHub Releaseの`sakura_setup.exe`を取得し、同じReleaseにある`release-manifest.txt`のSHA-256とPowerShellの`(Get-FileHash .\sakura_setup.exe -Algorithm SHA256).Hash`が一致することを確認してから手動で実行してください。

未署名installerは自動更新のAuthenticode検証を通らないため、自動取得・実行されません。updaterのfail-closed検証は変更していません。

アップグレードはversioned payloadのside-by-side切替で行われます。新しいpayloadの検証に失敗した場合は、TSF登録を新しい版へ切り替えずに中止します。
