# Sakura Input 2.0.11

- 短い読みを単独で変換したときに、IT用語集の語が一般的な語より先に出ないようにしました（#282）。たとえば「いこう」は「以降」、「しゃさい」は「車載」が先頭になります。用語集の語は2番目以降に残り、「移行処理」などの複合語ではこれまでどおり先頭に出ます。この調整で「くせ」が「曲」、「ふさい」が「夫妻」になるのを避けるため、「癖」と「負債」が先頭になるよう価格を調整しました。また、「かんし」は「関し」、「しょうがいじ」は「障害児」が先頭になります。
- #282の調整が変換時のIT用語補正で打ち消されていた8つの読みを直しました（#291）。「きょうかい」「けっかん」「したうけ」「しはらいさいと」「じょうちょう」「じょうほうろうえい」「ちょうか」「ていけい」を単独で変換すると、それぞれ「協会」「血管」「下請け」「支払いサイト」「上長」「情報漏洩」「釣果」「提携」が先頭になり、用語集の語は2番目になります。「境界意識」「冗長化」「下請法」など、これらの語を含む複合語は引き続き先頭に出ます。「みつもり」は先頭の「見積もり」は変わらず、2番目と3番目の候補が入れ替わります。

このリリースの検証は、辞書ビルダーと変換順位の単体テスト（修正前のコードでは失敗することの確認を含む）、出荷辞書での変換順位テスト、変換コーパス評価、ワークスペース全体のテスト、リポジトリのCIゲートです。インストールしたIMEでの画面上の変換確認は、リリース時点では行っていません。

このインストーラーはAuthenticode未署名です。手動導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では署名付き更新manifestによるサイズ・SHA-256・未署名状態の検証を行います。
