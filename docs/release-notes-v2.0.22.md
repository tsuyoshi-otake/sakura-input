# Sakura Input 2.0.22

このリリースは、動詞の活用形を辞書に増やし、それに合わせて変換と予測の候補の並びを整えたものです（#348、#390、#393、#392）。

- 「待つ」「読む」「飲む」「踏む」のように「る」以外で終わる五段動詞の活用形（待って、読んで、飲みます、待ったら、踏んで など）を辞書に加えました（#348）。
  - これまでは、Mozc の一般的な五段動詞の分類について「る」で終わる動詞の活用形しか作っていなかったため、「ふんで」「のみます」「まったら」「だした」などが、語幹と助詞の組み合わせや別の名詞として変換されていました。
  - 「く」「う」で終わる動詞は、かなだけでは音便の形が決まらないため、今回は対象外です。
  - カタカナや送りがなの合わない表記に語尾を付けてしまう生成（「ムスて」など）をやめました。
  - 予測では、増えた活用形が候補9件に入るため、「不躾」「服」「運転」「呼び出す」など8語で、表示されるまでに必要な入力が1文字増えるか、読みの半分では候補9件から外れるようになりました。
- 新しく作った活用形が、Mozc が持つ同じ読みの別の動詞の活用形より先に出るのを抑えました（#390）。「おしたら」で「押したら」より「推したら」が先に出ていたのを直しました。
- 入力ミスを救済する候補が、正しく入力した読みの候補より先に出るのを抑えました（#393）。
  - 「あっかした」が「明かした」に、「たして」が「出して」になっていたのを、「悪化した」「足して」に戻しました。
  - 救済候補に付ける不利の大きさを 1,200 から 1,900 に上げました。そのぶん、入力ミスを1つ含む読みの試験では、ミスが読みの途中にある 839 件のうち 17 件、末尾にある 2,773 件のうち 60 件が救済されなくなりました。
- 漢字の見出しのほうが同じかそれ以上によく使われる語では、かな書きの活用形を予測に出さないようにしました（#392）。
  - 「でまし」で「でました」、「おいしくな」で「おいしくない」が予測に出ていたのをやめました。「ひこ」で「飛行機」、「やき」で「野球」が予測の候補9件に戻りました。
  - 「くださって」「いただけます」のように、かな書きのほうがよく使われる語は、今までどおり予測に出ます。
  - 変換の候補は変わりません。かな書きの活用形も、変換では今までどおり出ます。
- 変換精度のゲートに、変換の例文37件と予測の単語5件を追加しました（変換1,574件、予測1,605件）。

2.0.21までに学習した内容と設定は、そのまま使われます。学習で誤った候補が先頭に固定されている読みは、学習の内容がこの修正より優先されます。

検証は、辞書の活用形生成と変換検索の単体テスト（修正前のコードで失敗することを含む）、実際の辞書を使った候補順位の回帰テスト（修正前の辞書で失敗することを含む）、リリース用辞書の検査、変換精度のゲート（変換1,574件、予測1,605件）、ワークスペース全体のテスト、リポジトリのCIゲートです。インストールしたIMEでの画面上の確認は、リリース時点では行っていません。

このインストーラーはAuthenticode未署名です。手動で導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では、署名付き更新manifestを使って、サイズ・SHA-256・未署名状態を検証します。
