# Sakura Input 2.0.23

このリリースは、正しく入力した読みが入力ミスの救済で別の語に置き換わる問題と、2.0.22 で増やした活用形が予測の候補を埋めてしまう問題を直したものです（#330、#354、#400）。

- 入力ミスを救済する候補が、正しく入力した読みの語より先に出るのを抑えました（#330）。
  - 「めがねをかけてるひと」が「メガネをかけてるヒント」に、「わたしにとってたいせつなひと」が「私にとって大切なヒント」に、「12ばんのばす」が「12番のパス」になっていたのを、「人」「バス」に戻しました。「しってる」も「してる」ではなく「知ってる」が先に出ます。
  - 入力した読みがそのまま辞書の語の読みである部分では、救済候補に付ける不利を 1,200 増やしました。救済候補は、今までどおり候補一覧に残ります。
  - 辞書の読み 96,902 件をそのまま入力する試験では、その語に変換される件数が 537 件増えました。そのぶん、入力ミスを1つ含む読みの試験では、14,294 件のうち 91 件で救済候補が先頭に出なくなりました。
- 「難しい場合」「よい機会」のように、Mozc が形容詞として登録している句のうち、表記が「い」で終わらないもの（読みの最後の「い」が「合」「会」のような漢字に含まれるもの）に活用語尾を付けないようにしました（#354）。
  - 「難しい場合て」「よい機会ない」のような、誤った語 2,570 件が辞書からなくなりました。
  - 変換精度のゲートの結果は変わりません。
- 予測で、1つの動詞の活用形が候補9件を埋めて、ほかの語を押し出すのを抑えました（#400）。
  - 動詞の活用形のうち、予測に出すのは「て」「た」「ます」の形と、「てる」「ている」「てない」の形だけにしました。「たら」「ない」「なかった」「ました」「たい」「ば」の形や「書こう」「書け」のような形は、予測には出しませんが、変換では今までどおり出ます。
  - 2.0.22 で予測に必要な入力が増えた8語のうち「振込手数料」「読み込める」「呼び出す」の3語が元に戻りました。予測の単語では 28 語で候補の出方が良くなり、悪くなった語はありません。
  - 「不躾」「服」「召し上がる」「踏み台」「運転」の5語は、まだ 2.0.22 と同じです。

2.0.22までに学習した内容と設定は、そのまま使われます。学習で誤った候補が先頭に固定されている読みは、学習の内容がこの修正より優先されます。

検証は、変換検索と辞書の活用形生成の単体テスト（修正前のコードで失敗することを含む）、実際の辞書を使った候補順位の回帰テスト（修正前の辞書で失敗することを含む）、リリース用辞書の検査、変換精度のゲート（変換1,574件、予測1,605件）、ワークスペース全体のテスト、リポジトリのCIゲートです。インストールしたIMEでの画面上の確認は、リリース時点では行っていません。

このインストーラーはAuthenticode未署名です。手動で導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では、署名付き更新manifestを使って、サイズ・SHA-256・未署名状態を検証します。
