# Sakura Input 2.0.8

- Sakura Padをパスワードで保護できるようになりました。パスワードを忘れた場合に備え、登録時に表示されるリカバリーキーでも復旧できます。保護を有効にすると、Pad全体をロックして開くときに認証を求めます。既存のPadは、利用者が保護を有効にするまで従来の保存形式のままです。
- メモごとの保護にも対応しました。各メモはPad全体とは別のパスワードまたはリカバリーキーで保護でき、対応するYubiKeyの登録・認証も利用できます。ロック中のメモはタイトルや本文を一覧、検索、コピーなどの画面操作に表示しません。
- オプションのTOTP確認を追加しました。これは同じWindowsユーザー内で行う追加確認であり、独立した暗号化やオンラインサービスによる二要素認証ではありません。同一ユーザー権限でデータを変更・巻き戻せる場合、この確認を回避できる可能性があります。
- Padの全体操作（設定とGitHub同期の準備中メニューを含む）は、サイドバー右下の「…」メニューにまとめました。メモのロック操作はエディター右上から行えます。
- Padのタイトル変更がメモ切り替えや終了の直前でも保存されるようにし、リストのタイトル表示とスクロール位置も更新後に保つようにしました。Padウィンドウは表示後も最前面を維持します。

保護機能の検証は隔離したテストデータを使っています。YubiKeyによるPad全体とメモ単位の認証経路は確認しましたが、物理YubiKeyを使ったメモ画面の一連の操作は未検証です。保存途中のプロセス終了からの復旧は検証していますが、電源断時の耐久性は未検証です。Padのデータ一式を過去の状態へ巻き戻せる同一ユーザー権限の攻撃者に対する保護はありません。実データの移行や、複数の予備キーの管理もこの検証の対象外です。大切なデータを保護する前にバックアップを取ってください。

このインストーラーはAuthenticode未署名です。手動導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では署名付き更新manifestによるサイズ・SHA-256・未署名状態の検証を行います。
