# Sakura Input 2.0.34

今回は、確定した表記を消して同じ読みを打ち直したときの変換を改善しました（#481）。

## 消して打ち直した直後の変換

確定した語をすべて消し、同じ読みを打ち直して変換したとき、通常の変換候補に読みと異なる別の表記があれば、消した表記以外が最初に選ばれるようになりました。

消した表記は候補に残り、これまでどおり選んで確定できます。複数の確定をまとめて消した場合、一部だけを消した場合や別の候補がない場合などは、従来どおりの選択です。

候補の並び順や、設定・学習・ユーザー辞書の形式に変更はありません。

このインストーラーはAuthenticode未署名です。手動で導入する場合は、GitHub Releaseの更新manifestに記録されたサイズ・SHA-256とファイルを照合してください。自動更新では、署名付き更新manifestを使って、サイズ・SHA-256・未署名状態を検証します。
