# Sakura Input 1.0.28

Sakura Pad の使い勝手を3点直すリリースです。IME 本体の変換、キー操作、辞書は 1.0.27 から変更していません。

## 主な変更

- 空のタイトル欄に「無題」と表示するようになりました。一覧が名前のないメモに書く語と同じで、初回起動の Pad が両ペインで同じ読み方になります。これは表示だけで、実際のタイトルとしては保存しません。名前を付けなかったメモは空タイトルのまま保存され、「無題」という名前が固定されることはありません。（#92）
- 検索欄・タイトル欄・本文欄で `Ctrl+A` の全選択が効くようになりました。Windows の標準 EDIT はこのショートカットを実装しておらず、これまでは何も起きていませんでした。`Ctrl+Alt+A`（一部キーボードの AltGr+A）は文字入力なので対象外、メモ一覧も対象外です。（#92）
- タイトルバー左端のアイコンを外しました。Pad はダブル Ctrl のジェスチャーで呼び出すもので、ウィンドウの並びから見分ける必要がないためです。システムメニューは従来どおり `Alt+Space` とタイトルバーの右クリックで開きます。（#92）

## 含まれないもの

- **GitHub 同期は未実装です。** Pad 下部バーの同期ボタンは「GitHub 未設定」と表示するだけで、通信は行いません。メモは端末内にとどまります。
- Pad の dark テーマと Windows ハイコントラストは、自動検証だけで実画面確認が済んでいません。
- 一覧の検索はタイトルと本文の両方に対する部分一致ですが、英字の大文字小文字を無視するだけで、全角・半角やひらがな・カタカナの正規化は行いません。

## 検証

- workspace 全体の format、Clippy（`-D warnings`）、`cargo test --workspace` に成功しました。
- 純関数の unit test に加え、実 renderer プロセスを使う回帰テストで、フレームの拡張スタイル、キャプションアイコンが空であること、タイトル欄のテキストが空のままであることを確認しています。
- 実画面のスクリーンショットで、空の Pad に「無題」「検索」が出てキャプションにアイコンがないことを確認しました。動作中の Pad へ実際に `Ctrl+A` を打鍵し、本文全体が選択されることも確認しています。

## 対応環境

Windows 11 build 22000 以降、x64、AVX 対応 CPU。32 bit ホスト用 DLL と ARM64 ネイティブ版は含みません。

## インストール前の確認

この Release は owner 承認済みの Authenticode 未署名版です。GitHub Release の `sakura_setup.exe` を取得し、同じ Release にある `release-manifest.txt` の SHA-256 と PowerShell の `(Get-FileHash .\sakura_setup.exe -Algorithm SHA256).Hash` が一致することを確認してから手動で実行してください。

未署名 installer は自動更新の Authenticode 検証を通らないため、自動取得・実行されません。updater の fail-closed 動作は維持されます。

アップグレードは versioned payload の side-by-side 切替で行われます。新しい payload の検証に失敗した場合は、TSF 登録を新しい版へ切り替えずに中止します。
