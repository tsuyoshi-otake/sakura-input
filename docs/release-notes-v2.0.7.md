# Sakura Input 2.0.7

- 開発者モードの入力履歴で、記録の追記が途中で失敗すると、次に正常保存した記録まで読み飛ばされる問題を修正しました。失敗した追記を元のファイル長へ戻し、復旧に失敗した場合は追加保存を停止します。履歴処理のエラーは、明示的な消去が成功するまで報告します。
- 入力履歴の消去中にヘッダーの書き込みや同期が失敗した場合、壊れたファイルへの追記を防ぐようにしました。消去は失敗として報告し、成功した再消去または次回起動時の検証後に記録を再開します。通常の文字入力は続けられます。
- 設定画面で入力支援をリセットしてからアプリ別設定を保存・削除しても、未適用の全体設定が保存されないようにしました。入力検証やアプリ別設定の保存が失敗した場合も、保存済みの設定状態を維持します。
- APIキーが長すぎる場合は他の設定を書き込む前に拒否します。設定保存の途中で失敗した場合は、保存済み・保存を確認できない・未実行の範囲を画面に表示します。複数の保存先を一括で取り消す変更ではないため、原因を解消してから再度［適用］してください。
- 起動時の自動更新確認は結果を設定画面に表示するだけとし、更新の有無や確認エラーによって編集中のページ・入力欄・フォーカスを切り替えないようにしました。「今すぐ確認」から更新が見つかった場合は、従来どおりインストール前に確認します。

このインストーラーはAuthenticode未署名です。手動導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では署名付き更新manifestによるサイズ・SHA-256・未署名状態の検証を行います。
