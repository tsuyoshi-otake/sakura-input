# Sakura Input 2.0.20

このリリースは、かな読みが数字の読みと誤判定されて、誤った候補が先頭（あるいは唯一の候補）に出ていた問題の修正です（#380）。

- 「ぜん」「びゃく」「ぴゃく」を含むかな読みが、数字として解釈されていたのを直しました（#380）。
  - 「しぜんに」が「4002」と解釈され、「自然に」が候補から消えて「4002」が確定されることがありました。「しぜんに」は「自然に」が先頭になります。
  - 同じ仕組みで「ごぜんに」が「5002」になっていたのを、「午前に」が先頭になるようにしました。
  - 日本語で「ぜん」「びゃく」は「さんぜん」「さんびゃく」（「なんぜん」「なんびゃく」）のあとだけ、「ぴゃく」は「ろっぴゃく」「はっぴゃく」のあとだけに現れる形です。この規則を数字の解釈に適用しました。
  - 「よんせんに」→「4002」、「ろっぴゃく」→「600」、「はっぴゃく」→「800」など、正しい数字の変換はこれまでどおりです。
- 変換精度のゲートに、この問題を再現する例文10件を追加しました（合計1,530件）。

2.0.19までに学習した内容と設定は、そのまま使われます。学習で誤った候補が先頭に固定されている読みは、学習の内容がこの修正より優先されます。

検証は、数字の解釈の単体テスト（修正前のコードで失敗することを含む）、実際の辞書を使った候補順位の回帰テスト、変換精度のゲート（追加した例文を含む1,530件）、ワークスペース全体のテスト、リポジトリのCIゲートです。インストールしたIMEでの画面上の確認は、リリース時点では行っていません。

このインストーラーはAuthenticode未署名です。手動で導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では、署名付き更新manifestを使って、サイズ・SHA-256・未署名状態を検証します。
