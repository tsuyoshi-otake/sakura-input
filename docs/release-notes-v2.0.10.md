# Sakura Input 2.0.10

- 変換の左文脈を改善しました（#273）。助詞などのひらがなをEnterで確定したあとも、次の変換が直前の語のつながりを使えるようになりました。確定直後にBackspaceやカーソル移動キーを押した場合は、消えた語や離れた位置の語を左文脈に使わないよう、左文脈を破棄します。
- 確定した語をすぐには学習しないようにしました（#275）。確定の学習は、次の操作でその確定が残ったと分かった時点で行います。確定直後にBackspaceで消した語や、確定の取り消し（Ctrl+Backspace）で戻した語は学習しません。
- #275の学習保留を見直しました（#277）。カタカナ変換やAI文章変換など学習しない確定を挟んだとき、その確定をBackspaceで消しても、ひとつ前の確定の学習が誤って取り消されないようにしました。確定の取り消しを処理している途中の語は、別のアプリでの変換や接続のリセットで学習されなくなりました。同時に保留できる確定の数を、プロセスが扱えるすべての入力セッション分に広げました。

このリリースの検証は、エンジンの単体テストと状態遷移テスト（修正前のコードでは失敗することの確認を含む）、ワークスペース全体のテスト、リポジトリのCIゲートです。実機のアプリ上でのBackspace・確定の取り消し・アプリ切り替えの組み合わせは、リリース時点では手動で検証していません。

このインストーラーはAuthenticode未署名です。手動導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では署名付き更新manifestによるサイズ・SHA-256・未署名状態の検証を行います。
