# Sakura Input 2.0.14

- ひらがなモードで英単語を打ったときに、ローマ字にならない英字が残る入力を変換すると、打ったキーそのままの半角英字が先頭の候補になるようにしました（#308）。たとえば「git」は変換前の表示が「ぎt」になりますが、Spaceで変換すると「git」が先頭で選択され、そのままEnterで「git」を確定できます。「nazka」は「nazka」が先頭、従来の先頭だった「なzか」が2番目になり、ほかの候補（「なぜか」などの訂正候補を含む）はその後ろに従来と同じ順で並びます。これまで必要だったF10での英字への切り替えは、この場合は不要です。全角英数の設定でも先頭の候補は半角のままです。
- 「nihon」「kanji」「konnichiha」のようにすべてかなになる入力、Shiftで始めた英字の入力、変換せずにEnterで確定する動作は変わりません。「make」→「まけ」のようにすべてかなになる英単語は対象外で、英字に戻すには従来どおりF10を使います。先頭に出る半角英字の候補は学習されず、学習の規則と学習ファイルの形式は変わりません。

このリリースの検証は、変換エンジンと変換コアの単体テスト（修正前のコードでは失敗することの確認を含む）、本番の入力処理スレッドでのスタック使用量の計測、ワークスペース全体のテスト、リポジトリのCIゲートです。辞書は2.0.13から変わっていません。インストールしたIMEでの画面上の変換確認は、リリース時点では行っていません。

このインストーラーはAuthenticode未署名です。手動導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では署名付き更新manifestによるサイズ・SHA-256・未署名状態の検証を行います。
