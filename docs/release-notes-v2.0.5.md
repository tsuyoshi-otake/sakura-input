# Sakura Input 2.0.5

- 単漢字の候補が通常の変換候補に押し出される問題を修正しました。候補の表示上限と変換探索の上限を分離し、登録済みの単漢字を選択できるようにしました。
- 文全体の変換結果と最初に表示される文節候補が食い違う問題を修正しました。「値段一覧も頂戴」などの変換結果を、表示と確定で維持します。
- 「みたいな感じ」「メンテナー」「クロック制御」「対応策」「肯定的な」「多言語反映」などの変換優先度を調整しました。同音異義語の選択と学習を維持しています。
- 開発者モードの入力履歴が容量上限に達した場合に、古い記録から整理して新しい記録の保存を続けるようにしました。保持期間30日・上限64 MiBは維持します。
- 入力履歴の整理が中断された場合、暗号化データと保存世代を検証して安全に判別できる状態を復旧します。内容を確認できないファイルや不明な状態は変更せず、エラーとして残します。

候補表示数の拡張に伴い通信形式を更新しています。インストーラーで各コンポーネントをまとめて更新してください。

確認した範囲では、登録単漢字23,688組の候補欠落は0件でした。候補追加・表示上限・履歴復旧の6判定は、MCC 24/24通りとMC/DC 12/12条件を検証しています。アプリ全体のMC/DC網羅率ではありません。

開発者モードで大きな入力履歴を保持している場合、履歴の検証・復旧中は起動を待つことがあります。約64 MiBの履歴コピーでは116秒でした。

このインストーラーはAuthenticode未署名です。手動導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では署名付き更新manifestによるサイズ・SHA-256・未署名状態の検証を行います。
