# Sakura Input 2.0.13

- 誤変換を選び直したあとも、誤った候補が先頭に残り続ける問題を直しました（#305）。同じ読み・同じ直前の文脈で、別々の候補を確定した学習が両方残っている場合は、最後に選んだ候補を優先します。たとえば「へんしん」で「変身」を何度も確定したあとでも、一度「返信」を選べば次から「返信」が先頭になります。競合する選択がない場合の学習順位と、学習ファイルの形式は変わりません。
- 外来語が漢字とカタカナの組み合わせに分かれて変換される3つの読みを直しました（#307）。「あんいんすとーる」は「アンインストール」（従来は「案インストール」）、「こんとりびゅーしょん」は「コントリビューション」（従来は「今鳥ビューション」）、「まいなんばー」は「マイナンバー」（従来は「枚ナンバー」）が先頭になります。辞書データだけの変更で、「インストール」「ナンバー」「案内」「毎日」などの単独の変換は変わりません。
- 「〜がわ」を含む語句が「川」になる問題を直しました（#306）。「さーばーがわ」は「サーバー側」、「くらいあんとがわでしょり」は「クライアント側で処理」、「りようしゃがわ」は「利用者側」になります。「石川」「市川」「多摩川」「内側」など、読み全体が辞書にある語はこれまでどおりです。長い語句の中にある固有名（たとえば「あおがわのほとり」）は、まだ「川」以外になる場合があります。この修正は変換エンジンと辞書の両方にまたがるため、同じバージョンのものを組み合わせて使います。
- キーを押し続けたときの入力が、開発者向け入力履歴の解析に混ざらないことを確かめるテストを追加しました（#309）。IMEの動作に変更はありません。

このリリースの検証は、学習・辞書ビルダー・変換の単体テスト（修正前のコードでは失敗することの確認を含む）、出荷辞書での変換順位テスト、ワークスペース全体のテスト、リポジトリのCIゲートです。インストールしたIMEでの画面上の変換確認は、リリース時点では行っていません。

このインストーラーはAuthenticode未署名です。手動導入する場合は、GitHub Releaseに掲載されたSHA-256とファイルのハッシュを照合してください。自動更新では署名付き更新manifestによるサイズ・SHA-256・未署名状態の検証を行います。
